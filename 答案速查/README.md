# 选择题答案速查

2020—2026 年各卷选择题的答案，用学生版做完后对答案用；详解见各卷教师版。由 [`scripts/gen_index.py`](../scripts/gen_index.py) 根据 `LaTeX源码/` 中的标注自动生成，请勿手改。

- 题号是 PDF 上印的题号；少数卷和原卷题号不一致，括号里注明原题号，见[存疑清单](../知识点索引/存疑清单.md)。
- “选择小问”是非选择题中的选择小问，如全国卷选考题的第（1）问、上海卷综合题中的选择，按出现顺序列出。实验题等用字母填空作答的小问，同一小问里列出了选项，或注明了“多选”“填正确答案标号”“填器材前的字母代号”等，也算选择小问；“滑片置于 A 端”这类填的是图中标号的不算。
- 标“（缺选项）”的，小问的选项在源文件里缺失，见[存疑清单](../知识点索引/存疑清单.md)。
