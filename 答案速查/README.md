# 选择题答案速查

2020—2026 年各卷选择题的答案，用学生版做完后对答案用；详解见各卷教师版。由 [`scripts/gen_index.py`](../scripts/gen_index.py) 根据 `LaTeX源码/` 中的标注自动生成，请勿手改。

- 题号是 PDF 上的卷内题号，全国理综卷按物理部分从 1 编号。与源文件所注题号不同时，括注源文件题号，见[存疑清单](../知识点索引/存疑清单.md)。
- “选择小问”按题面原有的分项和小问号列出，如“（1）B；（3）A；（5）A”。同一问有多空时按空序用顿号隔开，题面未编号的选择空只列答案。实验题等用字母填空作答的小问，同一小问里列出了选项，或注明了“多选”“填正确答案标号”“填器材前的字母代号”等，也算选择小问；“滑片置于 A 端”这类填的是图中标号的不算。
- 标“（缺选项）”的，小问的选项在源文件里缺失，见[存疑清单](../知识点索引/存疑清单.md)。
