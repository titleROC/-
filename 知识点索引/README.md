# 知识点索引

按知识点查 2020—2026 年 131 套卷中的 2112 道题。由 [`scripts/gen_index.py`](../scripts/gen_index.py) 根据 `LaTeX源码/` 中的标注自动生成，请勿手改。

- 每个章节一页，章节内按知识点分组；章节和知识点用的是题库平台的分类（例如动量归在“运动和力”下）。
- **题号**是 PDF 上印的题号。少数卷 PDF 题号和原卷题号不一致（上游合并、拆分了同号题，或原始材料缺题），这时括注原题号，如“17（原 16）”。
- **题型、分值、难度**来自平台标注。难度是平台给的难度值，0—1，越小越难，仅供参考。
- 题型带 * 的，平台标注和题目对不上，索引按题目结构作了订正或推断，见[存疑清单](存疑清单.md)。
- **题目**是题干开头，公式只做了粗略转写，复杂的公式用“…”代替。
- 全部题目的表格版：[`题目清单.csv`](题目清单.csv)，可以用 Excel 或 WPS 打开筛选。
- 选择题答案见[答案速查](../答案速查/README.md)。
