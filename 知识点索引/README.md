# 知识点索引

按知识点查 2020—2026 年 135 套卷中的 2161 道题。由 [`scripts/gen_index.py`](../scripts/gen_index.py) 根据 `LaTeX源码/` 中的标注自动生成，请勿手改。

- 每个章节一页，章节内按知识点分组；章节和知识点用的是题库平台的分类（例如动量归在“运动和力”下）。
- **题号**是 PDF 上的卷内题号。全国理综卷按物理部分从 1 编号。缺题时保留原题号的空缺。原卷中一道题的几个部分分开收录时，题号后标出部分，如全国卷选考题的“13（1）”“13（2）”、浙江卷实验题的“16-Ⅰ（1）”“16-Ⅱ”；个别 PDF 题号和原卷不一致的，括注原题号，如“17（原 16）”。
- **题型、分值、难度**读取自源文件。标为“推定”的分值仍待原卷核实，CSV 的“分值状态”列保留该标记。分值缺失时显示为“—”。难度沿用题库平台的数值，0—1，越小越难；没有平台数据时显示为“—”。
- 题型带 * 的，源文件标注和题目对不上，索引按题目结构作了订正或推断，见[存疑清单](存疑清单.md)。
- **题目**是题干开头，公式只做了粗略转写，复杂的公式用“…”代替。
- 全部题目的表格版：[`题目清单.csv`](题目清单.csv)，可以用 Excel 或 WPS 打开筛选。
- PDF 链接分别标出题目在学生版、教师版的起始页。下载后按标注的页码翻阅。全部 PDF 见 [Release「pdf」](https://github.com/titleROC/-/releases/tag/pdf)。
- 选择题答案见[答案速查](../答案速查/README.md)。
- 尚未收全的试卷及缺题范围见[补卷清单](../LaTeX源码/订正补丁/待订正清单.md#需后续补全的试卷)。
