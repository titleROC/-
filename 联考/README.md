# 重要联考（物理）索引

这里收录**大范围、官方组织的新高考适应性联考**的信息。这类考试由教育部考试院统一部署、各省（区）组织，
难度和题型被普遍视为当年高考的风向标。

> **为什么这里只有索引，没有 PDF？**
> 检索时能找到的联考物理卷，几乎都在付费会员、微信公众号或群、百度网盘或登录墙之后，
> 有的站点（如自主选拔在线）不允许境外访问；能免费查看的只有个别网页上的手机翻拍图，
> 带第三方水印和考生笔迹，也不完整（例如 2025 年河南卷只有 6 页中的 3 页）。
> 这些都达不到「高清 PDF」的要求，也不宜绕过付费墙抓取，所以没有放进仓库。
> 下表给出可查看的公开页面，拿到干净的 PDF 后可以按 `联考/<年份>_<联考名>/` 的结构补进来。

- 2025 八省联考对应省份 → 2025 年的四川、河南、云南、陕晋宁青、黑吉辽内卷

## 2. 其他常见大型联考（未收录）

各地还有很多由教研机构或出版商组织的大型联考，例如 T8 联考（八省八校）、百师联盟、天一大联考、
华大新高考联盟和金太阳联考。它们属于商业试卷，版权归命题机构所有，通常只在付费平台发布，
这里没有收录。
