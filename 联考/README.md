另外记录了5条尚未取得文件的线索。条目数不是完整试卷套数，图片数也不等于原卷页数；缺答案、部分答案、
省份适用范围待核等情况均保留在目录中。

这些是原始资料，尚未转写为本仓库的 LaTeX 学生版、教师版，也未计入131套正式高考卷或知识点索引。
来源文件常带转载水印，部分是扫描件或第三方解析版。仓库仍不提交试卷PDF；下载脚本把附件保存在本地缓存中。

## 目录与下载

- [资料目录 CSV](资料目录.csv)：可用 Excel 筛选年份、地区、缺项和来源。
- [资料目录 JSON](资料目录.json)：每条资料带来源页、附件直链、相对保存路径、大小和SHA-256，便于后续入库。
- [待补充来源](待补充来源.json)：会员/积分入口、失效下载入口及尚待拆分的理综卷，未计入已下载附件。

使用 Python 3 标准库，无需安装额外依赖：

```bash
python3 scripts/download_joint_exams.py --list
python3 scripts/download_joint_exams.py --exam adapt-2025-sichuan
python3 scripts/download_joint_exams.py --exam t8-2025-dec --exam t8-2026-dec-hubei
python3 scripts/download_joint_exams.py --all
python3 scripts/download_joint_exams.py --all --verify
```

默认保存到 `.cache/joint-exams/`，已由仓库的 `.gitignore` 忽略。全部原始附件约118 MiB。
用 `--output` 指定其他目录；图片顺序以JSON中的 `assets` 数组为准。
下载脚本复核SHA-256，已有且校验一致的文件直接跳过；校验不符时报告错误，不覆盖本地文件。
网站可能更新或删除文件，因此未来下载成功率和内容不一定与本次相同。

## 分类与核验说明

**官方适应性考试与名校模拟联考分开。** “八省联考”是常见检索名称，物理并非全国统一命题。
四川的命题分工见[省教育考试院公告](https://www.sceea.cn/Html/202411/Newsdetail_3986.html)及
[人民网报道](https://sc.people.com.cn/n2/2024/1105/c345167-41031127.html)。T8、江南十校等单列为名校或区域模拟联考。

**跨省版本不重复计数。** 2025年来源将陕西、山西、青海、宁夏合列，实际取得的PDF首页写“陕西”。
目录因此只确认陕西题面，把山西、青海、宁夏放在 `candidate_regions`，等待逐省核验。
2024年吉林与黑龙江在来源中合列一份解析，暂作一条记录；河南是理综卷，待拆出物理部分，不能算作第八套独立物理卷。

**参考答案与官方答案分开。** 中国教育在线汇总页明确说明答案非官方；其他来源也可能是第三方解析、
手写批注或简答结果。文件名写“答案”不代表已经证实是命题方标准答案。2021年福建图片只有部分答案，不能作为完整题卷。

已检查177个附件的文件格式、图片尺寸或PDF页数及SHA-256；14个PDF的144页均可渲染，并抽看了主要首尾页。
云南两份PDF存在交叉引用对象缺失警告，虽可渲染，仍须检查图形和字体。2024年安徽答案的图片数与标注页数不同，
仍需检查拼页或缺页。完整性和答案正确性尚未逐题验收，`import_status` 均为 `staging_only`。

下一步按“届别＋实际考试日期＋系列＋地区版本＋原卷题号”组织LaTeX转写，保留原文件哈希和来源，
逐题核对公式、图形、单位、选择题答案与解答。正式高考卷与这些联考是不同试题，不互相替代。
