  题库数据和 OCR 结果的多轮校对。用脚本逐题比对，28 题中有 25 题的题干与上游逐字相同，另外 3 题的差异见下文“相对上游的改动”。
- **配图**：49 张图都是上游 `figs/` 中的原图文件，复制后只按本练习的题号改了文件名，文件内容逐字节相同。
  上游的图取自原卷 PDF 的内嵌图或题库数据，不做 TikZ 重绘；个别组合图在上游已拆成单张子图，并去掉了图内的
  “A/B/C/D”“图 1/图 2”等字样，改由排版命令重新标注。
- 每题在 [`自感与涡流.tex`](../LaTeX源码/专题练习/自感与涡流/自感与涡流.tex) 中的注释都写明了上游源文件和配图的对应关系，

### 重新编译

需要的软件见仓库根目录 [README](../README.md#来源与重新编译)。

```bash
scripts/build_gaokao_pdfs.sh 专题练习     # 编译全部专题练习，生成学生版和教师版并复制到 专题练习/
```

编译试卷的 `scripts/build_gaokao_pdfs.sh 2020 2026` 也会顺带编译全部专题练习。
修改单个专题时，也可以用 `make -C LaTeX源码/专题练习/自感与涡流` 在源码目录里编译预览，
但要更新这里的 PDF，请用上面的脚本：它固定了 PDF 里的时间戳，内容没变时 PDF 逐字节不变。
