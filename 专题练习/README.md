需要的软件见仓库根目录 [README](../README.md#来源与重新编译)。

```bash
scripts/build_gaokao_pdfs.sh 专题练习     # 编译全部专题练习，生成学生版和教师版并复制到 专题练习/（不入库）
```

编译试卷的 `scripts/build_gaokao_pdfs.sh 2020 2026` 也会顺带编译全部专题练习。
修改单个专题时，也可以用 `make -C LaTeX源码/专题练习/自感与涡流` 在源码目录里编译预览。
编出的 PDF 不提交；改动合并到默认分支后，GitHub Actions 会重新编译并更新 Release 中的 PDF。

## 动量与碰撞

给动量、碰撞这部分比较薄弱的学生做专项练习。题目选自 2007—2026 年高考真题：
2020—2026 年的题取自本仓库的 [`LaTeX源码/`](../LaTeX源码/)；
2007—2019 年的题取自同一个上游档案库 [YLXDXX/gaokao-physics-archive](https://github.com/YLXDXX/gaokao-physics-archive)（提交 `5a60bb3`），本仓库没有收录这些年份。

- 按知识点分为九组，组内大致由易到难：
  一、动量、冲量和动量定理（第 1—6 题）；二、动量定理的应用：曲线运动与流体（第 7—13 题）；
  三、动量守恒定律：守恒条件、反冲与爆炸（第 14—19 题）；四、碰撞（第 20—28 题，含绳子突然绷紧）；
  五、常见模型（一）：子弹打木块与板块（第 29—32 题）；六、常见模型（二）：弹簧与斜面体（第 33—38 题，含弹簧一端靠墙）；
  七、实验：验证动量守恒定律（第 39—40 题）；八、综合应用（第 41—45 题）；九、挑战题（第 46—48 题，选做）。
- 前八组的开头各有 2—5 条「要点回顾」，提示本组用到的规律和容易出错的地方。
- 每题开头标出出处和难度：★ 基础，★★ 中档，★★★ 较难，★★★★ 挑战。难度参考档案库记录的得分率，并结合题目本身判断。
- 共 24 道选择题（其中多选 4 道）、22 道计算题、2 道实验题。建议分三次完成：第 1—19 题、第 20—38 题、第 39—48 题。
- 学生版只有题目，计算题后留有作答空白（与本仓库其他学生版的版式相同）。教师版每题后附答案和详解，书末附题目一览和选择题答案速查。
- 选修 3-5 合卷题（2011、2012 福建卷，2013 新课标Ⅰ、Ⅱ卷，2015 新课标Ⅰ卷，2016 全国Ⅰ、Ⅱ卷）只保留动量小问。

### 相对档案库的改动

题干、答案和详解照录档案库。每道题都按题意重新核算过答案，订正了下面几处：

- 第 29 题（2018 海南卷第 5 题）：**答案由 B 改为 C**。档案库按平台数据标 B，但它自己的异常记录写明原卷和解析都是 C，按题意计算也是 C；同时删去解析末尾关于答案冲突的说明。
- 第 8 题（2021 北京卷第 10 题）：B 选项的解析原用 $I=fT$ 算出摩擦力一圈的冲量为 $2\pi mr\omega$。摩擦力方向时刻在变，不能这样算，已改为用动量定理：转一圈动量变化为零，摩擦力的冲量为零。结论「B 错误」不变。
- 第 34 题（2007 四川卷第 18 题）：原卷没有解析，档案库里是占位文字，由编者补写了解析。
- 第 28 题（2013 新课标Ⅰ卷）：解析中 $v_1=\frac{v_2}{2}$ 补上负号，注明 A 碰后反向。
- 第 32 题（2025 浙江1月选考第 8 题）：解析中热量的算式把 $\frac12 mv_C^2$ 多写成 $\frac12\times 2mv_C^2$，已订正，结果 3 J 不变。
- 第 39 题（2024 新课标卷第 22 题）：题干「测出落点的平均位置 $P$ 与 $O$ 点的距离 $x$」改为 $x_P$，与后文一致；第（2）问第二空的答案去掉句末的「。」，避免与题干的句号重复。
- 第 40 题（2022 全国甲卷第 23 题）：表头 $k_2=\frac{v_1}{v_2}$ 与表中待求的 $k_2$ 冲突，改为 $k=\frac{v_1}{v_2}$，第（6）问补上「$k_2=$」；表格改为紧跟在第（5）步后面，不再浮动；答案按实验题写法手动编号。
- 第 41 题（2014 北京卷第 22 题）：解析第（3）问的中间式 $\frac12(m_A+m_B)v'^2=\frac12 m_Av_A^2=\frac12 m_Agh$ 有误，改为 $\frac14 m_Av_A^2=\frac12 m_AgR$，结果 0.25 m 不变。
- 第 46 题（2015 新课标Ⅰ卷）：解析中的条件 $v_{A2}<v_{C1}$ 改为 $\leq$，与后面的结论 $(\sqrt5-2)M\leq m$ 一致。
